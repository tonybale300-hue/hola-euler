# 实机测试证据

这些文件保留本次实际使用的测试驱动，供审查和复现准备，不属于初学者的逐行练习入口。

- blocks-v0.2.0.json 固定修订前的代码块编号。测试中发现的问题用明确的 JDK 21 路径等适配修正，不能将旧编号套入 v0.2.1 的命令清单。
- execution-results.json 保留 83 次执行记录，包括 6 次早期失败和后续复测。终端原始输出留在本地工作记录；此文件只保留必要状态，避免发布网络配置与终端信息。
- tunnel-results.json 是 Windows 客户端的真实 HTTP 隧道结果及独占端口冲突测试。
- installed-packages.txt 列出本次增加的 69 个包。Maven 依赖带入多套 Java，默认工具链仍为 Java 8，测试显式选择 JDK 21。
- Python 驱动面向本次虚拟机里的独立测试目录和账户，包含创建账户、服务和挂载实验。不能直接在已有同名对象的系统重跑。复现前必须检查名称、目录、端口、备份与清理流程。

普通用户为 eulercheck，管理步骤使用已有 root 连接。未创建任何免密 sudo 规则。SSH 转发仅临时授予测试账户，结束后原配置哈希已恢复一致；测试服务停止并禁用，试验密钥授权已撤销。保留文件与账户供复核，未重启虚拟机。
