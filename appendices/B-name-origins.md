# 附录 B 命令名称与英文关联

“词义关联”帮助记忆用途，不等于经过历史考据的命名全称。对于历史来源，下面只保留官方材料能支持的少数例子。其余以单词本义、工具官方名称或组合读法记忆，不补写命名者故事。

| 命令 | 关联 | 记忆重点 |
|---|---|---|
| pwd | print working directory | 打印当前工作目录 |
| cd | change directory | 改变目录 |
| mkdir | make directory | 创建目录 |
| ls | list | 列出名称 |
| cp / mv / rm | copy / move / remove | 复制、移动、移除 |
| rmdir / ln | remove directory / link | 删除空目录、建立链接 |
| touch | 触碰 | 主要更新时间戳 |
| cat | concatenate | 连接输入并输出 |
| printf | formatted printing | 按格式输出 |
| head / tail / cut | 头 / 尾 / 切取 | 选择所需文本 |
| sort / uniq / wc | sort / unique / word count | 排序、相邻去重、统计 |
| chmod / chown | change mode / change owner | 权限与所有者分开 |
| ps / id | process status / identity | 进程与身份查询 |
| DNF / RPM | Dandified YUM / RPM Package Manager | 软件包管理 |
| systemctl / journalctl | system control / journal control | 管理服务、读日志 |
| nmcli | NetworkManager command-line interface | 网络管理命令接口 |
| ssh / scp | Secure Shell / secure copy | 远程通信与传输 |
| tar | tape archive | 名称具有磁带归档历史 |
| grep | ed 的 g/re/p 操作 | 按模式选行并打印 |
| Vim | Vi IMproved | vi 的改进编辑器 |
| Bash | Bourne Again SHell | 与 Bourne Shell 的历史联系 |
| df / du | disk free / disk usage | 文件系统统计与路径用量 |
| lsblk / findmnt | list block devices / find mounts | 设备与挂载 |
| mktemp / javac / jar | make temporary / Java compiler / Java archive | 临时对象与 Java 工具 |

kill 的实际核心能力是发信号；less、top、Git、ping 保留工具名称与用途即可。不要为了凑英文缩写，把错误的名称解释再教给下一位读者。
