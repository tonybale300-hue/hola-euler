# 附录 E Linux 后续学习路线

## E.1 把本书项目再做两次

第一次从自己的笔记重做，记录还需要翻书的步骤。第二次从干净快照开始，只拿一页部署说明完成。能解释一次失败如何定位，比记住更多孤立选项更能检验基础是否扎实。

完成标准是能找到目录、辨认权限、查询包来源、定位进程、读取日志并验证端口和应用。遇到问题时，知道下一条查询在验证哪个猜想，才适合继续扩展系统。

## E.2 选择一个真实方向

准备学习 Java 后端，可以继续做数据库连接、配置分环境、测试与持续集成。每加入一个依赖，都记录启动条件、账户权限、失败表现和恢复方法。不要急着把所有组件搬到公网。

偏向系统管理，可以继续学习文件系统备份、逻辑卷、定时任务、资源限制和性能观察。磁盘写入实验另建专用虚拟盘，练习前确认没有重要数据。

偏向容器与云环境，可以在理解进程、网络和权限之后，再学习命名空间、cgroup、镜像与容器运行时。容器仍依赖宿主机内核，不能用“隔离”两个字省略权限与数据边界。

## E.3 读一份手册并提出一个问题

选一条最近使用的命令，读本机 man 页的名称、用法、选项和退出状态，做一个足够小的实验。先写预测，再运行，再解释差异。查阅网上资料时记录版本与日期，能把一个不准确的例子纠正清楚，也是一项实际成果。

需要向社区求助时，提供可复现步骤、环境版本和脱敏后的完整报错。问题解决后补充原因与处理结果。这个记录会成为你下一次独立处理问题的起点。
