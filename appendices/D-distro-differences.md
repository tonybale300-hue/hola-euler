# 附录 D openEuler、Ubuntu 与 CentOS 常见差异

跨发行版经验有帮助，但每次迁移都要重新确认版本和默认配置。下表比较常见工具家族，不承诺所有历史版本与裁剪环境都相同。

| 项目 | openEuler 本书环境 | Ubuntu 常见环境 | CentOS 相关环境 |
|---|---|---|---|
| 软件包家族 | RPM，常用 DNF | DEB，常用 APT/dpkg | RPM；DNF 或历史 YUM，随版本变化 |
| 包供应者 | 用 DNF 查询 | 使用该发行版工具查询 | 不沿用为 openEuler 的保证 |
| 网络管理 | 先确认 NetworkManager | 可能涉及 Netplan 与不同后端 | 不根据旧 network-scripts 教程推断 |
| 服务名 | 从本机单元查询 | 同一软件可能名称不同 | 同样以实际安装为准 |
| 安全机制 | 核对 SELinux 和防火墙实际状态 | 常见 AppArmor 等机制 | 默认及策略随版本不同 |
| 软件源 | 固定目标版本与架构 | 使用匹配 Ubuntu 版本的源 | 不混入 openEuler |

不要把 sudo apt install 后面换成一个 RPM 包名就称为迁移。除了安装工具，还要核对包拆分、配置路径、服务名称与安全策略。通用的路径、进程和 Bash 概念可继续使用，默认值需要重新查询。

本附录不提供生命周期日期表，避免把会变化的维护信息印成固定事实。选择系统时应读取相应项目当前官方生命周期资料。来源见 S01、S06、S25。
