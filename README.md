# Hola Euler

《openEuler Linux：从命令行到服务器实战》 · Alex 著

本地批阅初稿 v0.1-review。面向第一次系统学习 Linux 的大学生，目标环境为 openEuler 24.03 LTS SP4 / x86_64 / Bash。

按 chapters/ 中的编号阅读；答案集中在 answers/，补充查询材料在 appendices/。PDF 位于交付目录中。review/REVIEW.md 可记录逐章意见，review/VALIDATION.md 列出发布前的实机验证工作。

本书使用 AI 辅助资料整理、初稿撰写、练习设计、技术核查及排版。Alex 对最终内容选择、验证和发布负责。当前没有 GitHub 仓库链接，也没有公开发行许可。LICENSE 尚待作者决定。批阅意见可直接填写本地记录，公开 Issue 和贡献流程留待作者批准发布后建立。

排版使用 scripts/build_pdf.py，依赖 Python reportlab、pypdf 和本机中文字体。字体文件不随项目分发。
