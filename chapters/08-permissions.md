# 第 8 章 Linux 权限

## 8.1 为什么自己创建的文件也可能不能写

### 8.1.1 看懂三组 rwx

```bash
mkdir -p ~/linux-lab/permissions
cd ~/linux-lab/permissions
printf '%s\n' 'private note' > note.txt
chmod 600 note.txt
ls -l note.txt
```

chmod 关联 change mode，改变权限模式。600 的含义稍后解释。先观察权限区域，普通文件类型标记 - 后面依次是所有者、所属组、其他人的三组权限。r 是 read，读；w 是 write，写；x 是 execute，执行。

:::diagram permissions

对普通文件，r 允许读取内容，w 允许修改内容，x 允许尝试执行。文件有 x 不代表它一定是有效程序，也不保证解释器或加载器存在。系统首先根据身份选择适用权限类别，不能把所有者缺少的权限再随意从“其他人”补回来。ACL 等扩展权限机制会增加细节，本章先掌握基本模型。

### 8.1.2 数字来自三个位的组合

r 对应 4，w 对应 2，x 对应 1，每组相加。6 是读写，5 是读与执行，7 是三者都有，0 是都没有。600 表示所有者可读写，组和其他人都没有权限。644 常用于允许别人读取的普通文件，700 常用于只让自己访问的目录。权限应根据任务决定，不要把这些数当作任何场景的固定答案。

## 8.2 目录权限与文件权限不同

### 8.2.1 能列名字不等于能读取内容

目录的 r 允许读取目录项列表，x 允许搜索或穿过这个目录，w 配合 x 通常允许新增、删除或重命名其中的目录项。读取一个文件通常需要父路径各级目录的 x 和文件自身的 r。

删除文件主要检查父目录权限，文件本身只读不能阻止有权修改父目录项的用户删掉它。带 sticky bit 的共享目录还会增加删除限制，/tmp 经常使用这种机制。遇到删除失败，不要只盯着文件自身的 w。

### 8.2.2 使用符号方式增加一项

```bash
chmod u-w note.txt
ls -l note.txt
chmod u+w note.txt
mkdir private
chmod 700 private
ls -ld private
```

u 是 user，即所有者，g 是 group，o 是 others，a 表示全部类别。+ 增加权限，- 移除，= 设为指定权限。u-w 只移除所有者的写权限，u+w 把它加回。ls -d 显示目录本身的条目，避免误看目录内部文件的权限。

## 8.3 所有者和默认权限

### 8.3.1 chown 改变的是归属

chown 关联 change owner，用来更改所有者，也能指定组。普通用户不能随意把文件交给其他用户。只有专门的管理任务才需要 sudo。第 24 章把服务目录交给专用账户时会给出具体命令，当前无需改变实验目录归属。

递归选项 -R 会影响子目录中的大量对象。对 chmod -R 或 chown -R，必须事先确认绝对路径和内容。不要对整个家目录“试一个权限数字”。目录通常需要 x，数据文件往往不需要，一条数字递归套用可能同时破坏两类对象。

### 8.3.2 umask 从新建请求中去掉权限

```bash
umask
```

umask 可与 user file creation mask 关联，文件创建权限掩码。常见程序创建普通文件时请求 666，创建目录时请求 777，掩码按位移除权限。例如 022 常让这些请求变成 644 和 755。它不是简单十进制减法，而且程序可能主动请求更严格的权限；目录默认 ACL 也可能影响结果。修改 umask 不会追溯改变旧文件。

## 8.4 权限报错的检查顺序

看到 Permission denied，先运行 id 确认身份，用 pwd 确认位置，再用 ls -ld 检查父目录、ls -l 检查文件。若基本权限正确，还应检查 ACL、只读挂载和安全策略。Operation not permitted 可能涉及能力限制、文件属性或具体系统调用，不等于“加一个 w 就好”。第 23 章将把这些检查用于服务部署。

## 8.5 本章练习

- 不要往前翻｜文件的 x 与目录的 x 分别允许什么？
- 命令填空｜仅给所有者增加执行权限使用 chmod ______ script.sh。
- 看需求写命令｜让 note.txt 仅所有者可读写，让 private 仅所有者可访问。
- 看命令猜结果｜文件模式 444，但父目录允许你写入和穿过，是否绝对无法删除该文件？
- 找错误｜为了修复一个配置文件读取失败，把整棵目录改成 777 有何问题？
- 无提示实操｜创建一个私有目录和笔记，证明你检查的是目录本身与文件本身；解释每个数字，不要只背答案。
