# 第 15 章 磁盘、分区与文件系统

## 15.1 路径背后是怎样的存储

### 15.1.1 设备、分区和文件系统

磁盘或虚拟磁盘是存储设备，分区把设备划分成若干区域。文件系统在一个区域上组织文件内容与元数据。挂载把某个文件系统接到现有目录树中的一个位置，那个位置叫挂载点。逻辑卷还可以在设备与文件系统之间增加可管理的一层，本书只建立概念，不要求第一次学习就操作 LVM。

### 15.1.2 只读查看已经存在的布局

```bash
lsblk -f
findmnt /
df -h .
df -i .
```

lsblk 关联 list block devices，列出块设备；-f 显示文件系统信息。findmnt 关联 find mounts，查询挂载。df 与 disk free 关联，报告文件系统空间统计；-h 用适合阅读的单位，-i 查询 inode 使用情况。命令中的 . 让 df 找到当前目录所在文件系统。

看到 /dev/vda、/dev/sda 或 /dev/nvme0n1 时，不要假定哪一个一定是数据盘。它们是设备名称，随虚拟硬件和平台变化。/ 显示的是挂载点，通常由某个分区或逻辑卷提供，不能反过来把一个路径直接称为“整块磁盘”。

## 15.2 明明还有空间为什么写不进去

### 15.2.1 块空间与 inode 都可能用完

普通文件的数据要占空间，文件对象也需要元数据资源。大量小文件可能在字节空间用完之前消耗 inode。df -h 与 df -i 应一起查看。此外，配额、只读挂载和权限问题也会拒绝写入，不一定都是磁盘满。

```bash
du -sh ~/linux-lab
```

du 关联 disk usage，统计路径涉及的磁盘使用量。-s 只给汇总，-h 使用可读单位。du 与 df 的统计对象不同，二者不必完全相等。一个文件已经从目录中删除，但仍被进程打开，可能不再被 du 找到，却仍占文件系统空间。这与第 4 章删除名称、第 10 章进程持有文件的知识相连。

### 15.2.2 找到问题再回收空间

先确定哪个文件系统紧张，再定位具体目录。不要直接清空 /var/log，也不要对 /tmp 的全部内容执行不加判断的删除。日志可能正在被服务写入，临时文件也可能属于运行中的程序。真实系统应按服务日志轮转和数据保留策略处理。

## 15.3 挂载点会暂时遮住原内容

### 15.3.1 一次安全的内存文件系统实验

本节需要管理员权限，只在专用虚拟机进行。先建立新的空目录，确认它不是既有挂载点。tmpfs 是用内存及可能的交换空间支持的临时文件系统，不会在指定磁盘上格式化分区。下面限制最大容量为 16 MiB，实验只在本次运行期间存在。

```bash
mkdir -p ~/linux-lab/mount-demo
ls -la ~/linux-lab/mount-demo
findmnt --mountpoint "$HOME/linux-lab/mount-demo"
```

只有目录为空、findmnt 未显示已有挂载时，才执行挂载。

```bash
sudo mount -t tmpfs -o size=16M,mode=0755 \
  tmpfs "$HOME/linux-lab/mount-demo"
findmnt --mountpoint "$HOME/linux-lab/mount-demo"
df -h "$HOME/linux-lab/mount-demo"
sudo umount "$HOME/linux-lab/mount-demo"
```

mount 就是挂载，-t 指定类型，-o 给选项。umount 的名称是 unmount 的历史命令拼写，少一个 n，输入时留意。此处挂载根目录默认属于 root，普通用户可能只能查看，实验无需写文件。操作时留在挂载点外，避免自己的工作目录让卸载报告 busy。

### 15.3.2 不在初学实验里格式化真实盘

mkfs 可与 make filesystem 关联，会创建文件系统并可能破坏原有数据。fdisk 用于分区管理，dd 用于低层数据复制与转换。这些工具必须建立在明确的设备识别和备份基础上，本书不提供一条可误执行到系统盘的格式化命令。未来学习时应另加专用空虚拟盘，并通过容量、序列信息和挂载状态确认对象。

> 实机核验｜【待 openEuler 24.03 LTS SP4 实机验证】tmpfs 挂载实验与权限行为需在目标虚拟机核验。不要写入 /etc/fstab 作为本章练习，错误条目可能影响下次启动。

## 15.4 本章练习

- 不要往前翻｜设备、文件系统和挂载点如何连接起来？
- 命令填空｜查看 inode 使用量使用 df ______。
- 看需求写命令｜查看实验目录所在文件系统的空间，再统计实验目录自身占用。
- 看命令猜结果｜把文件系统挂到一个有旧文件的目录后，原来的文件一定被删除了吗？
- 找错误｜看到 /dev/sdb 就假定它是空盘并格式化，依据足够吗？
- 无提示实操｜只读绘出自己系统的根文件系统来自哪个设备或逻辑卷，记录容量与挂载点。

本章新命令为 lsblk / list block devices、findmnt / find mounts、df / disk free、du / disk usage、mount / 挂载、umount / 卸载。mkfs、fdisk、dd 在本章仅识别用途。七天后从路径反查设备，保持只读。
