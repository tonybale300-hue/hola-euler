# 第 2 章 Terminal、Shell 与 Bash

## 2.1 光标后面发生了什么

### 2.1.1 一个窗口，三层工作

你在窗口中输入 pwd，按回车后得到一个目录。显示字符、接收按键的界面叫终端，英文 terminal。解释命令语法、组织程序运行的程序叫 Shell。Bash 是一种 Shell，名字来自 Bourne Again SHell，与早期 Bourne Shell 有历史联系。[S03]

终端窗口可以运行 Bash，也可以运行别的 Shell。Windows 的 PowerShell 窗口不会因为长得像 Linux 终端就支持本书全部命令。请在 openEuler 的控制台或已登录 openEuler 的远程终端中操作。

### 2.1.2 先试一个容易看清结果的命令

```bash
printf '%s\n' 'Hello, openEuler'
```

printf 关联 formatted printing，即按格式输出。第一个参数 '%s\n' 是格式，%s 放入一段字符串，\n 输出换行。第二个参数是要输出的文字。两侧的单引号告诉 Bash 把里面的空格和符号作为文字的一部分。终端应显示一行 Hello, openEuler。这是由输入决定的教学预期，不是保存的目标系统终端记录。

与文字类似，命令也需要明确边界。printf '%s\n' 'two words' 传入一个含空格的文本参数；把单引号删掉，two 和 words 成为两个参数，该格式会分别用于它们。这为第 4 章带空格的文件名作准备。

## 2.2 分清命令来自哪里

### 2.2.1 内建命令与外部程序

```bash
type cd
type pwd
type ls
```

type 的普通词义是类型，这里显示 Bash 会怎样解释一个名字。cd 通常是 Bash 内建命令，即解释器本身实现的命令。ls 通常来自独立可执行文件，也可能被配置成别名。pwd 既可以由 Bash 内建实现，也可能存在外部程序。以自己的 type 输出为准。

cd 需要改变当前 Shell 的工作目录，所以它必须影响当前 Shell 自己。外部程序在自己的进程中改变目录，不会让父 Shell 自动跟着改变。第 10 章会解释进程关系。

### 2.2.2 请求帮助

```bash
help cd
ls --help
man ls
```

help 是 Bash 的内建帮助命令，适用于 cd 这样的内建命令。--help 是许多外部命令提供的帮助选项。man 来自 manual，打开手册页。手册常由分页器显示，按 q 退出，空格翻页，输入 / 后接词语可搜索。若 man 尚未安装，先使用 --help；第 9 章再通过仓库查询安装，不能把缺少文档程序误判为整个系统损坏。

## 2.3 少敲一点，少错一点

### 2.3.1 补全和历史

输入一部分路径后按 Tab，Bash 常能补齐唯一匹配项。出现多个候选时，继续输入更多字符。上、下方向键可以找回近期命令，先检查再回车。不要在历史命令里保存密码、访问令牌或数据库连接秘密。

Ctrl+C 通常请求中断当前前台任务。Ctrl+D 在空输入处表示输入结束，交互式 Shell 可能因此退出。它们不是同一个“取消”键。如果输入引号后忘了闭合，终端可能换到续行提示符；此时 Ctrl+C 可以放弃这一条未完成输入。

### 2.3.2 有意拼错一次

```bash
pwdd
```

预期会出现包含 command not found 含义的错误。它说明 Shell 没能把 pwdd 解析为可执行的命令。先对照拼写，再用 type 查询。以后还要检查 PATH，第 16 章会解释。不要看到这个错误就立刻下载来源不明的脚本。
