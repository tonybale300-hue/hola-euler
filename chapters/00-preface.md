# 第 0 章 如何使用本书

> 本章任务｜建立自己的实验目录，退出后还能重新找到它。

## 0.1 从一件小事开始

### 0.1.1 今天要留下什么

合上教材之后，能否自己建立一个目录，把文件放进去，再找到它？本书从这样的小任务开始。每章都要留下可以检查的结果，例如一个文件、一份日志或一个能够访问的服务。看懂一页之后，请把视线从书上移开，重新做一次。

本书按文件操作、系统管理、脚本与部署展开。前半部分不要求懂网络协议和操作系统原理。遇到第一次出现的概念，先用眼前的实验理解它。后面的章节会继续使用前面的目录、权限和文本处理知识。

### 0.1.2 本书实验约定

目标环境为 openEuler 24.03 LTS SP4，处理器架构为 x86_64，交互式命令解释器为 Bash。请在虚拟机中学习。虚拟机是一台由软件提供的计算机，它有自己的系统和虚拟磁盘；关掉虚拟机不会自动撤销磁盘上的修改，快照也不能代替长期备份。

全书把普通练习放在当前用户家目录下的 linux-lab 中。家目录用于保存自己的文件。第 1 章完成系统准备，第 3 章会解释目录路径。尚未准备环境的读者，可以先阅读，再回来执行下面三行。

```bash
mkdir -p ~/linux-lab
cd ~/linux-lab
pwd
```

mkdir 关联 make directory，创建目录。-p 允许所需父目录一并创建，目录已存在时不因此报错。cd 关联 change directory，改变当前位置。pwd 关联 print working directory，打印当前工作目录。~ 在这里由 Bash 展开为当前用户的家目录。三行分别输入，每行按一次回车。最后应看到一个以 /linux-lab 结尾的路径，用户名和前面的目录由你的系统决定。

> 实验边界｜普通文件操作只针对自己建立的实验文件。任何出现 sudo 的步骤都涉及更高权限，应先读解释再操作。正文代码没有提示符，方便复制；终端中已经显示的 $ 或 # 不属于要输入的命令。

## 0.2 怎样读一条命令

### 0.2.1 空格把任务分成几部分

```text
cp hello.txt backup.txt
|  |         |
|  |         +-- 目标名称
|  +------------ 源文件
+--------------- cp，复制
```

cp 关联 copy。整行要求读取 hello.txt，并写出 backup.txt。暂时不用运行，这两个文件将在第 4 章准备。命令的第一个词通常指定做事的程序，后面是选项与操作对象。选项改变做事方式，操作对象说明处理谁。它们都是命令行参数的一部分。

```text
cp [选项] <源> <目标>
```

这种写法是说明格式。方括号表示该部分可选，尖括号表示需要替换的内容，都不要照敲。真实 Shell 中这些符号还有别的含义，第 17 章会解释。某些命令支持 -r 这样的短选项与 --recursive 这样的长选项；是否等价，要看该命令自己的手册。一个命令的 -r 不能推导出另一个命令的 -r。

> 提示｜先读代码块前面的执行位置和准备条件，再逐行输入。故意拼错、访问不存在文件等实验预计会失败；不要把整章代码一次粘贴成脚本。

### 0.2.2 看结果而非只等一句成功

许多 Linux 命令成功时没有文字输出。创建目录后，提示符重新出现，只能说明前一个命令已经结束；应再查看目录确认结果。反过来，文字很多也不代表成功。出错时保留完整命令、当前路径、报错和当时的用户身份，这些信息比“不能用”更有帮助。

本书不把推演结果伪装成实机记录。“预期观察”表示根据命令语义应检查的现象。用户名、进程号、设备名和日期不会固定。本版已在目标虚拟机执行按章节组织的运行测试，并据此修正手册包、JDK 选择与 SSH 转发前提。预期失败、测试适配和未执行项分别记录；重启恢复按用户要求暂不验证。版本敏感部分使用统一标记。

> 验证状态｜【待 openEuler 24.03 LTS SP4 实机验证】表示目标环境的包名、配置、权限或运行行为还需要实机核对。此标记不是执行成功的证明。

## 0.3 给记忆留一次工作机会

### 0.3.1 四次短复习

完成一节后，十分钟内关掉示例，重做最短实验。一天后只看任务描述写命令。三天后给文件换一个名字，检查自己能否处理空格、路径和错误。七天后把本周学到的命令用于一个新任务，例如整理实验目录并打包备份。这些时间是便于安排的学习建议，不是保证记忆效果的固定公式。

每章的“不要往前翻”要求先解释，“命令填空”检查命令结构，“看需求写命令”要求自己组合，“看命令猜结果”帮助发现误解，“找错误”训练诊断，“无提示实操”检验能否独立完成。答案统一放在全书后部，先保留自己的答案再核对。

### 0.3.2 第一次学习记录

准备一页记录，写下系统版本、日期、今天完成的任务和一个仍不确定的问题。记录“权限不够，后来用了 sudo”过于粗略。应写清哪个文件、哪个用户、哪一项权限让操作被拒绝。第 8 章将提供检查方法。

## 0.4 本章练习

- 不要往前翻｜命令没有输出时，怎样判断它是否完成了目标？
- 命令填空｜打印当前位置使用 ______。
- 看需求写命令｜创建家目录中的 linux-lab 并进入。
- 看命令猜结果｜连续执行两次 mkdir -p ~/linux-lab，第二次会因目录已经存在而失败吗？
- 找错误｜有人把 cp [选项] <源> <目标> 原样输入终端，问题在哪里？
- 无提示实操｜重新登录，以普通用户进入实验目录，记录实际路径。

本章新命令与英文关联为 mkdir / make directory、cd / change directory、pwd / print working directory。cp 的第一次完整实验见第 4 章。复习时以自己的目录为准。
