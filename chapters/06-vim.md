# 第 6 章 Vim

## 6.1 能进去，也能出来

### 6.1.1 从一份自己的笔记开始

服务器上不一定有图形编辑器。Vim 可以直接在终端中编辑文本，名字来自 Vi IMproved，即对 vi 编辑器的改进。先查询 type vim。如果不存在，暂用前面的 printf 创建文件，到第 9 章按仓库查询方法安装所需编辑器后再回来完成本章。

```bash
mkdir -p ~/linux-lab/editor
cd ~/linux-lab/editor
vim note.txt
```

Vim 启动后默认处于普通模式。这个模式中按键通常是编辑命令。按 i 进入插入模式，再输入两行文字。按 Esc 回到普通模式，输入 :wq 并回车，保存并退出。w 与 write 关联，q 与 quit 关联。键序列不带反引号，也不要把 :wq 输入到 Bash 提示符后。

### 6.1.2 如果只是误打开

按 Esc，再输入 :q 回车可退出未修改的文件。如果修改过但不想保存，使用 :q!；感叹号表示放弃相关保护检查，会丢失本次未保存的修改。已写入磁盘的历史版本不会因此恢复。想保留修改但暂不退出，使用 :w。

## 6.2 让修改动作可控

### 6.2.1 移动、删除与撤销

重新打开 note.txt。普通模式中可以用方向键移动，也可以用 h、j、k、l 分别向左、下、上、右。先把精力放在模式上，不必强迫自己马上放弃方向键。

把光标放到一行上，按 dd 删除这一行。按 u 撤销，Ctrl+R 重做。按 yy 复制当前行，p 放到当前位置之后。数字通常可以修饰动作，例如 3j 向下移动三行。不要在插入模式中尝试这些命令，否则字母会变成正文。

### 6.2.2 查找比逐行移动更可靠

普通模式输入 /Linux 并回车，查找 Linux。n 跳到下一个匹配，N 反向查找。输入 :set number 显示行号，这只影响当前编辑显示。发现第几行的配置有问题后，可以输入 :12 跳到第 12 行。

要把全文中的 lab 改为 practice，可输入下面的 Vim 命令。

```vim
:%s/lab/practice/gc
```

% 代表全部行，s 关联 substitute，替换匹配文本。g 让一行内多个匹配都参与，c 要求逐个确认。模式采用正则表达式，不等同于任意文字的原样搜索，第 18 章介绍基本规则。初次批量替换时保留 c，比不看范围就替换更容易发现错误。

## 6.3 报错往往与文件有关

### 6.3.1 保存失败先检查路径与权限

编辑器可以打开一个你能读、却不能写的文件。保存时出现只读或权限错误，应检查文件和父目录权限。对系统配置，应先退出、备份并明确修改目的；第 8 章解释权限，第 23 章给出专用配置操作。不要为了存一行练习而把整个编辑器长期以 root 身份运行。

### 6.3.2 交换文件提示

异常断线后，Vim 可能提示存在交换文件。也可能是另一终端仍在编辑同一个文件。先确认是否还有编辑会话，必要时按提示恢复，再比较恢复内容与磁盘文件。不要不看说明就删除交换文件，那里面可能保留尚未保存的工作。读懂提示之后选择恢复、只读打开或退出。

## 6.4 本章练习

- 不要往前翻｜普通模式和插入模式分别解释按键为什么？
- 命令填空｜保存退出使用 ______，放弃未保存改动退出使用 ______。
- 看需求写命令｜显示行号并跳到第 5 行，写出 Vim 中要输入的命令。
- 看命令猜结果｜在普通模式按 dd 后按 u，当前行会怎样？
- 找错误｜在 Bash 输入 :wq 为什么无法关闭一个已经退出的 Vim？
- 无提示实操｜写一份三行笔记，复制一行、删一行、撤销，再搜索一个词并保存。用 cat 验证磁盘内容。

本章新工具为 Vim / Vi IMproved。编辑结束后复用 cat 检查，三天后只看任务重做一次。
